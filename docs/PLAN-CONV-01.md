## 2. Цели и не-цели

Цели: (G1) видеть конверсию по типу страницы и по месту CTA; (G2) увеличить долю посетителей статей, хабов и услуг, дошедших до звонка или формы; (G3) не навредить SEO и скорости, остаться в бесплатном тарифе Vercel, без сторонних сервисов, без хранения запросов и статистики на сервере.

Не-цели: правки SEO-текстов, заголовков и URL статей; возврат gtag; страница трихолога (см. `docs/IDEAS.md`); A/B-платформы.

Оценка успеха: объём ~1 000 визитов в месяц, статистической значимости не будет. Смотрим тренд за 4 недели после C7: доля сеансов с ключевым событием на статьях/услугах, распределение конверсий по `cta_source`, конверсия открытие → отправка квиза (база 40%), звонки по `reception_state`.

## 3. Решения владельца (зафиксированы)

1. Поиск: две переменные `NEXT_PUBLIC_SEARCH_ENABLED` (интерфейс) и `SEARCH_ENABLED` (сервер) для `.env`, `.env.local`, `env_example`, Vercel; отключает поиск везде. Первый коммит.
2. Реестр CTA: рубрика/услуга → тексты RU/RO, подпись для квиза; запасной вариант «консультация», чтобы новые статьи получали CTA сами.
3. Квиз с предзаполнением, вариант A: чип «Процедура: …», в заявку уходят `procedure` и `source`, шагов меньше. Вторая форма «Получить консультацию» удаляется везде.
4. Карточка CTA в конце статей и на хабах; фото врача `public/assets/img/ecaterina_pintea_ava.png` через `next/image` (WebP, quality 75). Файл заменят через ~2 дня с тем же именем, код от содержимого не зависит.
5. Десктоп: слева круглое фото врача в одной «таблетке» с кнопкой «Записаться онлайн»; справа зелёная кнопка звонка.
6. Мобильные: один контейнер `fixed bottom-0`: розовая «Записаться» (анимация сохраняется) + зелёная «Позвонить»; cookie-баннер внутри того же контейнера под кнопками; после «Принять» панель опускается сама, без измерений.
7. Индикатор часов, Europe/Chisinau, без исключений по датам, без текста про ожидание звонка:
   - день приёма (вт, чт, пт, сб) и 13:00–18:00 → зелёный;
   - день приёма вне часов → красный;
   - нерабочий день (пн, ср, вс) → индикатор не показывается.
   Логика берётся из `isReceptionOpenAt` / `isReceptionWeekday` в `src/lib/contact-reception-schedule.ts`.
8. Попап на ~60% прокрутки: статьи, хабы, страницы услуг. Не главная, не контакты, не поиск, не `/ads`. Раз за сессию, пауза 7 дней, никогда после заявки. Один оверлей одновременно.
9. Тексты CTA на RU и RO (через humanizer, на согласование до коммита C3).
10. Instagram-ссылка в профиле: `https://meddera.md/?utm_source=instagram&utm_medium=bio_website`.
11. Трихолог: только в IDEAS, нужно одобрение врача.

## 6. События GA4: каждый CTA отправляет событие

Принцип (по образцу существующих): действие пользователя шлёт то же событие, что и аналогичный существующий CTA; место различает параметр `cta_source`. Новых ключевых событий не появляется, список ключевых событий в GA4 не меняется (пять прежних). Одно действие = одно событие, дублей быть не должно.

| Действие | Событие | Ключевое | Параметры |
|---|---|---|---|
| Открытие квиза с любого CTA (панель, плавающая кнопка, карточка, тизер) | `lead_sticky_cta_click` | нет (шаг воронки) | `button_name: appointment` (как сейчас), `event_label: sticky_lead` (как сейчас), `cta_source`, `procedure` |
| Квиз отправлен | `lead_sticky_form_sent` | да | как сейчас + `cta_source`, `procedure` источника открытия |
| Звонок с нижней панели и десктопной зелёной кнопки | `phone_click_fixed_1` | да | `button_name: animate_button`, `event_label` как сейчас, `cta_source: dock_call` или `float_call` |
| Звонок из карточки статьи/хаба и любая другая ссылка `tel:` на сайте (подвал, SEO-блоки услуг) | `phone_click_simple1` (существующий глобальный `TelClickTracker`) | да | как сейчас + `cta_source` (`article_card_call`, `hub_card_call`, иначе `inline_tel`) |
| Страница контактов (кнопка звонка, форма) | `phone_button_contacts1`, `form_sended_1` | да | без изменений, получают общий контекст |
| Тизер показан | `cta_teaser_view` | нет | `cta_source: teaser_scroll60`, `procedure`, `scroll_pct: 60` |
| Тизер закрыт крестиком | `cta_teaser_dismiss` | нет | те же |
| Клик по тизеру | отдельного события нет: открывается квиз, срабатывает `lead_sticky_cta_click` с `cta_source: teaser_scroll60` | нет | — |

Значения `cta_source`: `dock_book`, `dock_call`, `float_book`, `float_call`, `article_card`, `article_card_call`, `hub_card`, `hub_card_call`, `teaser_scroll60`, `inline_tel`.

Механика, чтобы ничего не забыть и не задвоить:
- Звонки на нижней панели, в карточках и в SEO-блоках — настоящие ссылки `<a href="tel:">`. Глобальный `TelClickTracker` читает у ссылки `data-cta-event`, `data-cta-source`, `data-cta-procedure`: если `data-cta-event` задан, шлёт именно его (например, `phone_click_fixed_1`) вместо `phone_click_simple1`. Так один клик даёт ровно одно событие и ссылка остаётся ссылкой (долгое нажатие, копирование номера).
- Открытие квиза идёт только через `openLeadQuiz({ source, procedure })`; событие `lead_sticky_cta_click` отправляется внутри этой функции, вызов без `source` не проходит типизацию.
- Проверка `scripts/verify-cta-events.mjs` (статическая): в `src` нет вызовов `openLeadQuiz` без `source`, нет прямых `sendGa4Event('lead_…')` вне хоста квиза, у каждой ссылки `tel:` из компонентов CTA есть `data-cta-source`.
- Сценарный тест (Playwright, перехват `/api/ga4-collect`): по каждой поверхности один клик → ровно одно событие с ожидаемыми именем и `cta_source`.
