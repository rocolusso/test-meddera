## Общий прогресс

План масштаба контента по-прежнему ориентируется на **~1600 статей** (16 рубрик × ~100). По факту в коде сейчас:

```
План:     ████████████████████████████████████████ 1600 статей (цель)
Факт:     ████████░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░  306 статей (~19%)
```

**Выполнено:** **306** статей с `kind: 'article'` в `registry` + **6** хабов → **312** маршрутов `/blog/[slug]` и `/ro/blog/[slug]` при сборке.

## Созданные рубрики (6 из 16)

### Топ-6 (в продакшен-структуре)

| № | Рубрика | Статей (кластер) | Примечание | Прогресс к 100/рубрика |
|---|---------|------------------|------------|-------------------------|
| 1 | Дерматолог | 50 | Part 1 + Part 2 | 50% |
| 2 | Ботокс | 50 | Part 1 + Part 2 | 50% |

Контент смешанный: ранние статьи Part 1 преимущественно развёрнутые; Part 2 во многих рубриках — компактный шаблон (информационный блок, 3 секции H2). При необходимости отдельные материалы можно расширять точечно.

## Детальная статистика

### Маршруты и сборка

| Проверка | Статус |
|----------|--------|
| `npm run build` (Next 16, **`--webpack`**) | Ожидается успешная сборка после изменений |
| Статические страницы блога | ~312 slug × RU + RO + пагинация (см. вывод `next build`) |
| `npm run verify:blog-content` | Проверка: у каждого `id` из метаданных есть ключ контента |

### Полезные артефакты

| Файл / скрипт | Назначение |
|---------------|------------|
| `generated/blog-article-final-urls.txt` | Список **только Part 2** (150 статей, RU+RO URL); пересборка: `npm run generate:blog-urls` |
| `scripts/verify-blog-metadata-content.mjs` | Метаданные ↔ ключи в файлах контента (в т.ч. `lip-cluster-article-content.ts` для inline) |
| `src/blog-data/registry.ts` | `ORIGIN` для canonical/JSON-LD; **`blogPathRu` / `blogPathRo`** для относительных ссылок в телах статей (локальный dev без ухода на прод) |

## Что осталось до цели «топ-6 × 100 статей»

Ориентир **600** статей по шести рубрикам: сделано **296** в кластерах (+ **10** отдельных lip в registry). Остаётся добрать **~294** статьи в кластерах (партии 51–75 и 76–100 по каждой рубрике — см. `BLOG_TODO.md`).

Дальше — **10 новых рубрик** (ещё ~1000 статей по плану) и SEO/техфаза.

## Ключевые метрики

**Сейчас**

- Сборка: webpack (`next build --webpack`).
- TypeScript: проходит при чистой сборке.
- Переводы RU/RO: у всех статей в registry.
- Переключатель языка в телах статей: относительные пути (`blogPathRu` / `blogPathRo`).

**Цель плана**

- 1600 статей, 16 рубрик, sitemap/JSON-LD по мере расширения — см. `BLOG_TODO.md`.
